# Simple Calculator Web App

## About
This project is a simple calculator web application developed as part of the CodeOrbit Tech Web Development Internship.

It performs basic arithmetic operations using HTML, CSS and JavaScript.

## Features
- Addition, subtraction, multiplication and division
- Decimal number support
- Clear (AC) and delete (DEL) buttons
- Division-by-zero error handling
- Keyboard input support
- Responsive calculator interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Enter numbers and choose an arithmetic operation.
5. Use AC to clear the calculation or DEL to remove the last digit.

## Project Structure
- index.html — calculator structure
- style.css — calculator design and responsive layout
- script.js — arithmetic operations and input handling
